# Raw Dataset

The original source dataset used for the E-Commerce Business Intelligence & Customer Analytics project.

## Download

The full dataset is available in the [GitHub Releases](https://github.com/asharyuvraj-source/ecommerce-business-intelligence/releases/tag/v1.0.0) section.

Download the original dataset from the project release assets before running the data preparation workflow.

## Purpose

The raw dataset serves as the input for data inspection, cleaning, preprocessing, SQL analysis, and Power BI reporting.
